# Investment Calculator

広告なし・オフライン対応を目標にした Android 向け PWA。USD/JPY は手入力し端末（localStorage）へ保存します。`$ → ¥` は結果×レート、`¥ → $` は結果÷レートです。未設定・ゼロ・負数では換算しません。

## 使い方

静的ファイルを HTTP で配信して Chrome で開き、「ホーム画面に追加」を選びます。`node tests.mjs` で計算ロジックを検証します。

### Windowsでのローカル起動

`start-calculator.bat` をダブルクリックします。Chromeで `http://127.0.0.1:8080/` を開きます。サーバーはバッチの黒い画面を開いている間だけ動作し、停止するにはその画面で `Ctrl+C` を押します。8080番ポートが既に使われている場合、既存プロセスには触れずに停止します。

四則演算はCASIO JS-20DB型の左結合・即時評価です。演算子は確定前なら置換でき、結果の直後に数字を入力すると新しい数値入力を開始します。定数計算は同じ演算子を2回押して設定します。たとえば `23 + + 12 =` の後に `45 =` を押すと `68` です。通常の `23 + 12 =` は定数計算になりません。定数計算中は式表示に `K` を表示し、＝を押すたびに定数演算を続けます。

% は現在値÷100ですが、加減算の右オペランドでは元の値に対する割合として扱います。たとえば `100 + 5% = 105`、`500 - 20% = 400` です。除算は小数12桁で切り捨て、表示時に末尾ゼロを省略します。換算結果は次の計算に使用でき、次の数字入力では新しい入力を開始します。キーボードでは数字、`.`, `+`, `-`, `*`, `/`, `%`, Enter、Backspace、Escapeを利用できます。メモリー機能は v1.1 候補です。
